## User story
As a Kid in Nursery or KG, I want the question and the choices to be pictures, with the question spoken, so I do not have to read.

Persona: Kid.

## Technical context
- TV `QuizQuestion`: `question`, `options`, `answer` — **no image**. - Mobile `Models.kt` has unused `imageUrl` on a different DTO. - `KidQuizConfig.autoDictation = false`.

## Acceptance
1. Success: Nursery / LKG / UKG can show a question image and image options (all images or all text, never mixed — `study-shield/quiz-schema.md`). Auto-dictation **on by default** for those grades unless parent turns it off on Kid Detail.
2. Failure: TV Retrofit. AI-generated architecture diagrams. Mixing text and image options in one question.

## API / data contract impact
Optional image fields on QuizQuestion in both Kotlin copies, and on the backend question payload. The TV must not download those images.

## Testing requirements
Young-grade quiz: spoken question, picture options, parent can disable TTS on Kid Detail.
