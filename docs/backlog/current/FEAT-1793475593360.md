## User story
As a Parent, I want a 4-digit PIN on this phone, so Start quiz can be gated without an email reset.

Persona: Parent.

## Components

- `krushnatkhawale/study-shield` — mobile

## Technical context
```kotlin // StudyScreens.kt SettingsScreen Switch(checked = true, onCheckedChange = {}) ``` Headline “Parental PIN” / “Require PIN to unlock manually” — **no storage, no prompt**.

## Acceptance
1. Success: 4-digit PIN in `SessionManager` (EncryptedSharedPreferences or existing prefs). Gate **Start quiz** (and unlock-from-phone if you use it), **not** the first-run stepper.
2. Failure: PIN on TV. Email-only recovery.

## API / data contract impact
None

## Testing requirements
Switch off = no prompt. Switch on = Start quiz asks PIN.
