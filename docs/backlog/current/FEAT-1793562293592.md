## User story

As Engineering, I want a production boot to hide the API map and database details, so a public deploy does not publish the service layout.

Persona: Engineering.

## Components

- `krushnatkhawale/study-shield-backend`

## Technical context

`SecurityConfig` permits `/swagger-ui/**`, `/api-docs/**`, and `/actuator/**` with no token. `JwtAuthFilter.shouldNotFilter` skips those same prefixes. `application.yml` sets `management.endpoint.health.show-details` to `always` and exposes `health,info`. There is no `application-prod.yml` override. The regression suite only needs `/actuator/health` to report UP.

## Acceptance

1. Success: With the prod profile, `/actuator/health` returns the status and no datasource, disk, or component details. `/swagger-ui.html` and `/api-docs` are not public. The regression profile can still read `/actuator/health`.
2. Failure: A request with no token on the prod profile does not receive the OpenAPI document. A refused docs request does not fall through to a public copy of the map.

## API / data contract impact

None

## Testing requirements

Boot the prod profile and GET `/actuator/health`, `/swagger-ui/index.html`, and `/api-docs` with no token. Assert health has status only, and the docs paths are not 200. Boot the regression profile and assert `/actuator/health` still returns UP.
