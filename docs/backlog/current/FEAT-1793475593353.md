## User story
As Engineering, I want one shared check that the mobile and TV command models match, so a new field cannot land in only one copy.

Persona: Engineering.

## Components

- `krushnatkhawale/study-shield` — mobile, tv

## Technical context
- `InterruptionCommand` / `QuizResultMessage` / `TtsCapabilitiesMessage` duplicated: - `mobile/src/main/java/com/kaushalya/interrupter/data/Models.kt` - `tv/src/main/java/com/kaushalya/interrupter/InterruptionCommand.kt` - TV `QuizQuestion` has **no** `id`; mobile’s does. - Tests: no round-trip. Docs say “update both”.

## Acceptance
1. Success: CI fails if the two models diverge. Adding a field is one PR: both copies + golden JSON fixture.
2. Failure: “Remember to update both” as the only control.

## API / data contract impact
None

## Testing requirements
`./gradlew :mobile:test :tv:test` (or shared module test). Change one field, confirm the test fails until both match.
