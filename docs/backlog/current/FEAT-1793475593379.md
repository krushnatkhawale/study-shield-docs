## User story
As Engineering, I want a guarded upload key and a release signing config, so a signed bundle can be built without committing the keystore.

Persona: Engineering.

## Components

- `krushnatkhawale/study-shield` — mobile, tv

## Technical context
Release builds have no guarded upload key. There is no `keystore.properties.example`, and signing secrets must never be committed.

## Acceptance
1. Success: A guarded upload key exists and release builds produce signed AABs.
2. Failure: Commit the keystore, real passwords, or `keystore.properties`.

## API / data contract impact
None

## Testing requirements
`./gradlew :mobile:bundleRelease` (and `:tv:bundleRelease` if applicable)
produces signed `.aab`; `jarsigner -verify` passes; `git status` shows no secrets.
