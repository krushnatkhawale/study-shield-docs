## User story
As a Parent, I want two free quizzes and then one plain sentence about more, so a pay step never appears on the TV.

Persona: Parent.

## Technical context
- `QUIZZES_PER_CLASS = 2`, `ContentTier.FREEMIUM`. - `ExpUpgradePromptDialog`: after first **Trial** quiz, ask to **update class** — not pay.

## Acceptance
1. Success: First two class quizzes always play. Then one mobile sentence “More class 4 quizzes”.
2. Failure: Ads on wrong answers. TV paywall. Per-question IAP.

## API / data contract impact
A persisted unlocked flag for a class, read by the mobile pack list. The TV payload does not gain a paywall field.

## Testing requirements
Third pack for a class blocked on phone; TV never shows a pay UI.
