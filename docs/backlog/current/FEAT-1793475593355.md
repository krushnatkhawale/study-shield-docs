## User story
As an Operator, I want reported questions in an admin inbox the same day, so I can blacklist one without a deploy.

Persona: Operator.

## Components

- `krushnatkhawale/study-shield-backend`
- `krushnatkhawale/study-shield-backend-admin`

## Technical context
- Mobile `QuizReviewScreen` → `FeedbackRepository` → `PUT /api/v1/questions/{id}/feedback`. - Backend `QuestionFeedbackController` upsert per `(account_id, question_id)`. - Admin `QuestionEditorDialog` has **Blacklisted**; bundles skip `blacklisted` questions.

## Acceptance
1. Success: Admin home/inbox: recent downvotes/reports, question text, grade, subject, count. Operator can blacklist without a deploy.
2. Failure: Public comments. Voting on TV. Auto-delete questions on one downvote without a human.

## API / data contract impact
Add an admin list of question feedback. Keep the existing parent PUT /api/v1/questions/{id}/feedback.

## Testing requirements
Downvote from mobile; row appears in admin; blacklist; new bundle omits it.
