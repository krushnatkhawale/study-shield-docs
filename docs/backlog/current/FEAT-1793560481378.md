## User story

As a Parent, I want Select on Quiz Setup to send that quiz for the child I picked, so the button does what its label says.

Persona: Parent.

## Components

- `krushnatkhawale/study-shield` — mobile

## Technical context

Quiz Setup is a drawer screen (`Screen.QuizSetup` in `StudyScreens.kt`). `QuizSetupScreen` loads quizzes for the selected child, then the Select button's click is empty (`TODO: schedule from quiz`). The working send path is already Content Selection through `StudyViewModel`. TV stays thin: this does not add HTTP or a catalog on the TV.

## Acceptance

1. Success: On Quiz Setup, Select sends the chosen quiz for the selected child using the same mobile send path as Content Selection. The TV plays that quiz for that child.
2. Failure: When the send cannot reach the TV, the parent sees an error. The click is not silent, and the TV is not left on a previous child's lock.

## API / data contract impact

None

## Testing requirements

Open Quiz Setup with two children, pick the second, tap Select, and confirm the command carries that child's name and that quiz. With the TV unreachable, confirm the parent sees an error and no command is left half-sent. Update `study-shield/docs/SCREEN_FLOWS_MOBILE.md` for the Select action.
