## User story
As a Kid, I want the idle TV to say it is ready to play, with the IP only in the footer, so the screen does not look like a network setup page.

Persona: Kid.

## Components

- `krushnatkhawale/study-shield` — tv

## Technical context
TV idle in `MainActivity` still leads with "Interrupter Ready!" and "Connect using IP". A 15 second ring then `moveTaskToBack` must stay, so the TV is not held on that screen. Pairing-by-code (SS-EXP-02) is in rejected/ and is not part of this feature.

## Acceptance
1. Success: Idle shows "Ready to play", with the device name and IP in the footer. The parent can still connect by NSD or by the manual IP that already works.
2. Failure: The idle screen adds a room code, a browser, or an ad, or the IP stays the hero line.

## API / data contract impact
None

## Testing requirements
`:tv:assembleDebug`. Phone still connects with NSD and with manual IP.
