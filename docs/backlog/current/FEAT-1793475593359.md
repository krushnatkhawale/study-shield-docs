## User story
As a Kid taking Hindi, I want the questions in Hindi script, so the subject is not English text with an India topic.

Persona: Kid.

## Technical context
- `QuestionBankContent` header: Hindi = English text, India topics. Nursery Hindi is traffic lights / peacock in English. - Loader sets quiz language `"English"`.

## Acceptance
1. Success: Hindi-subject items Nursery–class 5 in Devanagari. Auto-dictation uses `hi-IN` for that subject (or kid greeting language — pick one rule and document it).
2. Failure: Translating Math word problems in the same PR unless required.

## API / data contract impact
Hindi-subject items in the bank payload use Devanagari. No new endpoint. Quiz language must not be forced to English for that subject.
