## User story
As Engineering, I want the API host injected per build type, so release does not bake in a hardcoded Render URL.

Persona: Engineering.

## Technical context
`private const val BASE_URL = "https://study-shield-backend-komv.onrender.com"` is compiled into every build. There is no way to point a debug build at local/staging, and changing environments requires a source edit and rebuild.

## Acceptance
1. Success: API base URL is injected per build type/flavor, not hardcoded in source.
2. Failure: the card's Do not list is violated, or the TV gains a parent control.

## API / data contract impact
None

## Testing requirements
Debug and release artifacts report different base URLs; prod release points at the
production host; no URL literal remains in `RetrofitClient.kt`.
