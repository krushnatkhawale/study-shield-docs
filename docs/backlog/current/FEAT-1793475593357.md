## User story
As a Parent, I want one picture of a phone, a TV, and a router when we are not on the same Wi-Fi, so I know what to fix.

Persona: Parent.

## Technical context
- `StudyRepository.probeTtsLanguages`: fail fast `IllegalStateException("NOT_ON_WIFI")`. - `StudyScreens.kt` maps that to a sentence about saving greeting language. - `TvManagementScreen` / Library: empty discovery text “Searching…” / “Scan stopped”.

## Acceptance
1. Success: When the phone is not on Wi-Fi, or discovery finds nothing, show one picture of a phone, a TV, and a router. Use that same picture for the TTS probe. Do not build the rejected pairing-code flow.
2. Failure: Dump AP isolation logs in the parent UI.

## API / data contract impact
None

## Testing requirements
Phone on cellular, TV on Wi-Fi: picture, not a stack trace.
