## User story
As a Kid, I want the TV remote to only pick answers, so I never open a parent menu or exit on my own.

Persona: Kid.

## Technical context
- `MainContent`: `BackHandler` no-op while a command is active. - `onKeyDown`: pause, then **double-press exit** (`showExitConfirm` / `ExitConfirmOverlay`). - Results: no buttons, 4s auto-close (`QuizResultsScreen`).

## Acceptance
1. Success: During quiz, remote only selects answers. Back/Home do not open a menu; optional toast-level “Ask mum/dad to stop on the phone”.
2. Failure: TV PIN. Kid profile picker on TV. HTTP.

## API / data contract impact
None

## Testing requirements
During MCQ, Back does not exit immediately. Phone unlock still clears state.
