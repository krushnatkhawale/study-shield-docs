## User story
As Engineering, I want a thin-TV checklist on TV pull requests, so a review catches HTTP, a kid menu, or a protocol edit in only one module.

Persona: Engineering.

## Technical context
`study-shield` has no pull request template. TV changes can merge without a check for HTTP, a kid menu, or a protocol edit in only one module.

## Acceptance
1. Success: Checklist: no kid menu, no HTTP on TV, D-pad+OK, no kid Exit, APK size delta, both protocol copies, TTS English fallback.
