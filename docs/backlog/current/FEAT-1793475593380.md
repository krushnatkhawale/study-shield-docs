## User story
As Engineering, I want release builds to stop logging bodies and headers, so tokens and student data do not land in logcat.

Persona: Engineering.

## Technical context
`HttpLoggingInterceptor.Level.BODY` plus a custom `RestCall` interceptor that `peekBody(Long.MAX_VALUE)` on *every* response are added unconditionally — active in release. This logs auth tokens and student data, and buffers every response body.

## Acceptance
1. Success: Release builds emit no request/response bodies or headers to logcat.
2. Failure: the card's Do not list is violated, or the TV gains a parent control.

## API / data contract impact
None

## Testing requirements
Release build's logcat shows no `RestCall` / `Authorization` / response bodies;
`strings` on the release APK contains no `RestCall` tag; debug logging still works locally.
